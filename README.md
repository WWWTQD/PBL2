---

## 🚀 Introduction

PBL2 is a project developed to build a complete **routing and delivery simulation system**.

The primary purpose of this application is to simulate logistics operations on a graph-based city map (intersections and roads). It allows users to experiment with various order assignment algorithms and observe the calculated routes and driver movements dynamically.

## ✨ Main Features

* 🗺️ **City Graph Management:** Generate, render, and manage a map consisting of intersections and connecting edges.
* 📦 **Entity Simulation:** Interactively add, edit, or remove `Warehouse`, `Driver`, and `Customer` nodes via the UI.
* 📊 **Algorithm Evaluation UI:** Render detailed algorithm history tables and colorize active paths on the map.
* 🚚 **Real-time Logistics Simulation:** Generate driver schedules and visually simulate their movement along the calculated routes.

---

## 🧠 Core Algorithms & Logic

The system implements advanced pathfinding and assignment algorithms to optimize logistics operations:

### 1. Pathfinding & Routing (`CityMap.cpp`)
* **Dijkstra's Algorithm:** Calculates the shortest distance from a single node to all other nodes. Acts as the foundational algorithm for routing and TSP.
* **Path Reconstruction & Visualization:** Utilizes Dijkstra's results to trace back the optimal path, dynamically coloring edges on the UI.
* **Nearest-Neighbor TSP Heuristic:** Solves the Traveling Salesperson Problem by iterating Dijkstra from the current node to iteratively select the closest customer/destination.

### 2. Order Assignment Strategies (`Warehouse.cpp`)
The system provides multiple approaches to assign orders to drivers:
* **Random & Greedy:** Baseline assignment strategies.
* **Hungarian Algorithm:** Solves the minimum-cost assignment problem based on a driver-to-order cost matrix.
* **K-Means Clustering:** Groups orders spatially based on location or driver capacity.
* **K-Means + Hungarian:** Biases the assignment costs using clusters before applying the Hungarian algorithm for optimal grouping.
* **Cluster + TSP:** Clusters orders per driver and then executes the TSP algorithm within each specific cluster.

### 3. Simulation Mechanics
* **Driver Movement (`DriverRoute`):** Tracks the active route state, progress, and waiting times of each driver.
* **Real-time Updates (`RunAllDriversLogistics`):** Continuously updates driver coordinates on the map based on the exact paths generated by Dijkstra and TSP.

## 💻 How to Run

General requirements:
- **MinGW G++ Compiler**
- **CMake** (v3.30 or later)
- **SDL2 & SDL2_ttf Libraries** (Included in the project directory)

### 1. Run using CLion (Recommended)

Open the project folder in CLion and let CMake load the project.

```bash
# Reload CMake Project to update library paths
# Click the 'Run' button (Shift + F10) targeting PBL2_PROJECT
```

The graphical window will launch automatically.

### 2. Run using Terminal (CMake)

Open your Terminal at the project's root directory:

```bash
mkdir cmake-build-debug
cd cmake-build-debug
cmake ..
cmake --build .
```

After the build completes, run the generated `.exe` file.
